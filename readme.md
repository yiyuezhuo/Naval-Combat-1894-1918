# Naval Combat 1894-1918

A naval combat subsystem prototype  extracted from my game in development, Meiji Oligarchy. The game is essentially a successor to the naval combat system of [First Sino-Japanese War](https://github.com/yiyuezhuo/Late-Qing-Naval-Combat-Demo).
